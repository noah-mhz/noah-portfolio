# Mochi's Card Nook — homepage concept (anonymised)

A neutral copy of a cozy trading card shop homepage Noah designed as a pitch.
The business's name, wordmark, mascot, pet photos, posters, set names, address and social
handle are replaced with original illustrations and placeholders.

Single `index.html` with inline CSS/JS; GSAP 3.12.5 + ScrollTrigger from cdnjs. Fonts are bundled
in `assets/fonts`. Serve with `python3 -m http.server`. Bag and newsletter are demos; nothing is sent.
