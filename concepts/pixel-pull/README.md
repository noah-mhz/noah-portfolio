# Pixel Pull — homepage concept (anonymised)

A neutral copy of a trading card store homepage Noah designed as a Shopify Online Store 2.0 pitch.
The business's name, logo, mascot, photos, posters and address are replaced with an original
brand, generated posters and fictional details. Product images belong to their publishers.
The "Why" design notes are Noah's own.

Static, no build. Fonts are bundled in `assets/fonts`. Serve with `python3 -m http.server`.
