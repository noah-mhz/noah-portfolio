# Little Rösti — homepage concept (anonymised)

A neutral copy of a homepage concept Noah designed for a rosti café pitch.
The business's name, logo, photos, story and contact details have been replaced:
illustrations in the same palette, sample menu copy and bracketed placeholders.

Static, no build: HTML + CSS + ES modules, GSAP from a CDN, fonts bundled in `assets/fonts`.
Serve with `python3 -m http.server` and open `index.html`.
