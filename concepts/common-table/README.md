# Common Table — homepage concept (anonymised)

A neutral copy of a restaurant homepage Noah designed as a pitch.
The business's name, logo, photos, menu, address, phone and social handle are replaced with
placeholder images, a sample menu and placeholder details.

Single `index.html` with inline CSS/JS; GSAP 3.12.5 + ScrollTrigger from cdnjs. Fonts are bundled
in `assets/fonts`. Menu, events and visit details live in the `CONTENT` object.
