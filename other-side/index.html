02 · Build notes

How this site is built

Five true statements about this page, each with a reading taken from your browser right now.

  1. B-1

    One page, three worlds

    Each world is a section of a single HTML page. Hash routes (#fable, #neon, #hollow) switch between them, so links can point into a world and the back button works.

  2. B-2

    One library, loaded late

    HTML, CSS and plain JavaScript, with no build step. Motion runs on the browser's Web Animations API. The one exception is the building at the top of this world: Three.js with custom GLSL floors, loaded only when you enter. Four typefaces are self-hosted.

  3. B-3

    One type system, three voices

    Geist Mono and Archivo carry navigation and reading everywhere. Each world has its own display face, and the selector's title is fitted so every letter can hand over in place.

  4. B-4

    Worlds load when you enter

    Screens for a world you have not entered are not downloaded. They load lazily when the world opens.

  5. B-5

    Motion you can switch off

    With reduced motion turned on in your system settings, every transition becomes an instant cut and nothing moves on its own.

B-6 · Experiment

Ask the build notes

A small Claude model answers questions about how this site is made, using only the notes above and a short list of facts. When the notes don't cover something, it says so. Your question is sent to Anthropic's API to be answered; this site doesn't store it.

Enteringthe Hollow

Where unfinished things live. For now it holds three studies made while building this site. Other experiments are in progress and will appear here when they are ready.

Studies

Study 1 · Typography

Hand-over

How the title on the first screen changes typeface. Families can't be blended, so each letter fades into its counterpart in the same place, and the word never breaks. Pick a voice.

The light

A line hidden under the surface that only a moving light can read. Drag across the dark with a pointer or a finger, or focus it and use the arrow keys.

Study 3 · GLSL

Ink

Ink dropped on wet paper, written as one fragment shader with no library. Each drop spreads along fractal noise, so its edge frays like paper fibres; as it dries, a darker tide-line gathers at the rim. Press or drag on the sheet, or focus it and press Enter.
